# Unraid templates

Unraid Community Applications templates by devclinton.

| App | Template |
|-----|----------|
| [putio-sync](https://github.com/devclinton/putio-sync) | [putio-sync.xml](putio-sync.xml) |

putio-sync is an independent project and is not affiliated with Put.io.

To install without Community Applications: Docker › Add Container, then paste the raw
template URL, `https://raw.githubusercontent.com/devclinton/unraid-templates/main/putio-sync.xml`,
into Template.

The source copy of each template lives in its app's repository
([putio-sync: `packaging/unraid/putio-sync.xml`](https://github.com/devclinton/putio-sync/blob/main/packaging/unraid/putio-sync.xml)).
Keep the two in sync.
